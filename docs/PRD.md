# BoltSnap PRD

## 1. 目的

ブラウザ上の画面を高速・ローカル完結でキャプチャし、PNG としてダウンロード / クリップボードコピーできる Chrome 拡張機能を提供する。

## 2. スコープ（MVP）

### 2.1 機能要件

| ID | 機能 | 概要 | 優先度 |
|----|------|------|--------|
| F-01 | フルページキャプチャ | スクロール合成でページ全体を PNG 化。**デフォルト** | 必須 |
| F-02 | 可視領域キャプチャ | 現在のビューポートのみ PNG 化 | 必須 |
| F-03 | 範囲選択キャプチャ | ドラッグで選択した矩形のみ PNG 化 | 必須 |
| F-04 | ローカル保存 | `chrome.downloads` で PNG をダウンロード | 必須 |
| F-05 | クリップボードコピー | `navigator.clipboard` で画像書き込み（任意） | 必須 |
| F-06 | Popup UI | モード選択／キャプチャ実行／進捗表示 | 必須 |

### 2.2 スコープ外

- Firefox / Safari 対応
- クラウドアップロード（S3, Drive 等）
- PII 自動マスキング、注釈編集（矢印・テキスト・ぼかし）
- OCR、PDF 書き出し

## 3. 非機能要件

| カテゴリ | 要件 |
|----------|------|
| セキュリティ | 外部通信なし。API キー等を保持しない |
| パフォーマンス | 1280×2400px 程度のページを 3 秒以内にキャプチャ完了 |
| プライバシー | ユーザーが明示的に発動したタブのみ対象（`activeTab`） |
| 配布 | パブリック OSS（MIT）。社内固有情報を含めない |

## 4. 主要ユースケース

US-01 〜 US-04（`docs/user-stories.md` 参照）

## 5. UI 方針

- Popup サイズ：320×200 px 程度
- UI 文言は 30 字以内
- MUI ベースのコンポーネント構成
- デフォルト選択：フルページ

## 6. 成功指標（MVP）

- `npm test` が全てパス（Tier1 / Tier2）
- 代表的な長いページ（ブログ記事・Wikipedia など）でフルページキャプチャが破綻しない
- キャプチャ → 保存までの一連動作がクリック 2 回以内で完了する
