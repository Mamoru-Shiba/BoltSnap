# ユーザーストーリー

## US-01: フルページキャプチャ（デフォルト）

> **As a** 記事や長いダッシュボードを残したいユーザー
> **I want to** Popup を開いて「キャプチャ」ボタンを押すだけで
> **So that** 現在のページ全体が PNG として自動的にローカル保存される

**受入基準**
- Popup を開いた直後のデフォルトモードは「フルページ」である
- 追加設定なしでダウンロードが始まる
- ヘッダー固定・遅延描画の一般的なページで破綻しない

## US-02: 可視領域キャプチャ

> **As a** 画面上に見えている範囲のみを記録したいユーザー
> **I want to** モードを「可視領域」に切替えてキャプチャする
> **So that** 現在のビューポートだけが PNG として保存される

## US-03: 範囲選択キャプチャ

> **As a** ページの一部だけを切り出したいユーザー
> **I want to** モードを「範囲選択」にして画面上をドラッグする
> **So that** 選択した矩形のみが PNG として保存される

## US-04: クリップボードへコピー

> **As a** キャプチャを即座に貼り付けたいユーザー
> **I want to** 「クリップボードへコピー」を ON にする
> **So that** PNG ファイル保存に加えて画像がクリップボードへ書き込まれる
