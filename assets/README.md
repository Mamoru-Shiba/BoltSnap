# assets/

デザインソース素材を置くディレクトリ。

## icon-source.png

BoltSnap の元アイコン画像（2000×2000 PNG）。`src/BoltSnap/app.ico`（exe とトレイのアイコン）の元ネタ。

## app.ico の再生成

背景（四隅の薄いグレー）を透過させ、16〜256px を 1 つの .ico にまとめる。
Python（Pillow）で、四隅から塗りつぶして透明にし、余白を切り詰めた正方形にしてから `sizes=[(16,16),(20,20),(24,24),(32,32),(40,40),(48,48),(64,64),(128,128),(256,256)]` で保存する。
